blockmp4

動画をブロックで再生するデータパックの作成ツール

K2Z/角角砂糖( https://www.youtube.com/@K2Z-角角砂糖 )氏の作品に影響を受け、ブロック更新によるアニメーション制作を手軽に試行できるツールを開発しました。Minecraft Java Edition 26.3にて動作確認済みです。

本ツールは、動画ファイルを Minecraft Java Edition のデータパック（ZIP 形式）に変換します。作成した ZIP をワールドの datapacks フォルダに配置すると、地面に設置したブロックのスクリーンで動画を再生できます。MOD・プラグインは不要です。

変換処理はすべてブラウザ内で行われます。動画ファイルが外部に送信されることはありません。

処理が終わるまで、このタブを閉じないでください。

4ワールドへの導入

ダウンロード

  1. ダウンロードした ZIP を、解凍せずにワールドの datapacks フォルダへ配置してください。
  2. ゲーム内で /reload を実行してください（ワールドに入り直しても構いません）。
  3. /function blockmp4:wand で杖を入手し、地面を見ながら「設置」の杖（絵画）を 2 回使用するとスクリーンが設置されます。 「再生 / 一時停止」の杖（黄緑の染料）で再生を開始します。

同じ名前の ZIP を差し替える場合は、ワールドを閉じてから行ってください（ワールドを開いている間はファイルが使用中のため、置き換えられません）。新しい名前の ZIP であれば、ワールドを開いたまま配置して /reload を実行できます。

datapacks フォルダの場所

シングルプレイの場合：ワールド選択画面でワールドを選択し、「編集」→「ワールドフォルダーを開く」で開いたフォルダ内の datapacks フォルダです。

例：C:\Users\(ユーザー名)\AppData\Roaming\.minecraft\saves\(ワールド名)\datapacks

サーバーの場合：world\datapacks です。コマンドの実行には、チートの許可（サーバーの場合は OP 権限）が必要です。

ゲーム内での操作（杖・コマンド）

/function blockmp4:wand で 8 本の杖を入手できます。手に持って右クリックで使用します。

設置（絵画）1 回目で設置範囲を黄色の枠で表示します。緑の印が左奥の角となり、手前と右方向に広がります。同じ位置で 2 回目を使用すると設置します。
再生 / 一時停止（黄緑の染料）停止中は再生、再生中は一時停止します。
停止（赤の染料）停止して最初のフレームに戻ります。
戻る（光の矢）・進む（矢）10 秒戻る / 進みます。スニーク中に使用すると 1 フレームずつ移動します。
動画の切り替え（本）次に設置する動画を切り替えます。
取り消し（回収コンパス）表示中の枠を消去します。枠がない場合は、最後に設置したスクリーンを撤去し、地形を元に戻します。
撤去（バリア）最も近いスクリーンを撤去し、地形を元に戻します。

同じ操作はコマンドでも行えます（いずれも /function blockmp4: に続けて入力します）：start・pause・resume・stop・seek {t:30}（30 秒の位置へ移動）・seek_frame {f:300}・skip {t:-10}・skip_frame {f:1}・undo・remove・next・video/(名前)・memory {mb:1024}・uninstall

データパックを取り外す前に、/function blockmp4:uninstall ですべてのスクリーンを撤去してください。

スクリーンの大きさと負荷の目安

スクリーンが大きいほど、また FPS が高いほど負荷が増えます。以下は、動きの多い MV を使用して作者の環境で検証した結果です。

  • 縦 128（228×128）・20 FPS：等速で再生
  • 縦 162（288×162）・20 FPS：ほぼ等速（負荷の高い場面でわずかに遅延）
  • 縦 256（455×256）・10 FPS：ほぼ等速（「色の不感帯」を 0.05 に設定した場合）

処理が追いつかない場合でも映像は崩れず、再生速度が遅くなります。
